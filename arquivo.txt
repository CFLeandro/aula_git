git init (inicia)
git config --global user.name "nome do usuário"
git config --global user.email "email do usuário"
git status (indica o que está havendo)
git add (põem certo arquivo para ser commitado)
git commit -m "comentário" (salva o arquivo)
git restore (restaura o arquivo)
git log (mostra tudo que foi feito)
git branch develop (cria outra linha de uso)
git switch develop (altera)
git merge develop (merge a develop com a master)
git branch -M main (renomeie a branch master para main)
git remote add origin "URL do Repositorio" (linkar arquivos no github)
git push -u origin main (envia a branch main para o github)
git pull -u origin main (baixa o que tiver no repositório no computador)
git fetch (sincronizar o local com o github)
git clone "URL do repositório"
